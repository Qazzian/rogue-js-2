# APPENDIX I: GENERATING THE DUNGEON

The rooms and passages of the
labyrinth come to life as the Heroes
explore. They are randomly
generated using the passage and
room generation tables, so the
Heroes won't know what they're
going to find until they get there.
You should only place a new
dungeon sections in during
Exploration
The following rules show how to
place new dungeon sections.

## Placing New Sections
The GM places all newly discovered dungeon sections. They
have a fairly free choice, so long as
they follow these simple guidelines:
• Passages are always straight,
unless a junction is placed.
• Rooms must always share a wall
with the passage or room from
which they were entered, with
corners meeting up for board
sections where possible.
• Passages discovered beyond
rooms run alongside the room,
not away from it, with corners
meeting up for board sections
where possible. At least one
passage section must share a
wall with the room, but any others
may be placed to the left or right.
Obviously, such a passage will
have two ends which must be
generated.
• Save for special Quest Room
sections, all passageways and
small room sides are five-spaces
long. Rooms must be placed to
match up against a single (or for
long room sides, double) length
of corridor. Rooms must be
placed similarly to match up each
five spaces from one edge,
against five other spaces from
one other edge.

## Re-Using Dungeon Sections

As the dungeon grows, it is
inevitable that the GM will find that
they occasionally runs out of a
certain sort of dungeon section. In
this case, they can remove
previously-placed sections for use
as the newly-discovered sections.
These should be taken from a part
of the dungeon as far away as
possible from wherever the Heroes
are at the time. When (or if) they
return to that part of the dungeon,
the expedition map can be used to
replace explored sections and any
relevant features back in their
correct position.
When you start a new level, it's
best to clear away all the previous
level's sections to leave the table
clear for new discoveries.

## Overlap

The GM should not place new
sections so that they overlap
existing ones.
If a large room is too large, use
the smaller size. If this doesn't fit,
the door is clearly a false one that
doesn't lead anywhere!
If there isn't space for the number
of passages generated, use as
many as you can fit in. If a junction
has an exit that leads straight into a
wall, replace it with one that doesn't.
If a passageway’s junction would
lie in another section, replace the
passageway with a dead-end.
If all possible exits are blocked,
add extra lengths of passage until
one isn't.
In all cases, where overlap
causes a problem, the GM has the
discretion to use a suitable
alternative to the result rolled.
